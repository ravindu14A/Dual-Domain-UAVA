# Unmanned Dual Domain Drone

This repository holds all simulations, control code, AI models and other useful stuff related to project 30 of the 2026 DSE of Aerospace Engineering at TU Delft.

## Getting started

Please use conda to install an environment with all the correct packages installed. To do this please run the following command:

```bash
conda env create -f environment.yml
```

or to update the packages if the environment has been changed:

```bash
conda env update -f environment.yml --prune
```

It automatically creates an environment called Aquaerial which can be used to run the python scripts.
